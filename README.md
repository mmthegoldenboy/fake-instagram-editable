# 가상 인스타그램 (피드 + 프로필)

피드와 프로필만 작동하는 가상 인스타그램 페이지입니다. DM, 검색, 릴스, 알림 아이콘은 보이기만 하고 눌러도 반응하지 않습니다.
편집 모드에서 게시물(작성자, 시간, 사진, 내용, 댓글, 반응 수)과 프로필을 직접 수정할 수 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 페이지 뼈대 |
| `style.css` | 디자인 |
| `app.js` | 동작과 편집 기능 |
| `data.json` | **게시물과 프로필 내용.** 방문자는 이 파일의 내용을 보게 됩니다. |
| `images/` (선택) | 사진을 저장소에 직접 넣을 때 사용하는 폴더 |

## 1. GitHub Pages로 배포하기

1. GitHub에서 **New repository**를 누르고 저장소를 만듭니다. 이름은 예를 들어 `insta`로 하고 **Public**으로 설정합니다.
2. 저장소 화면에서 **Add file → Upload files**를 누르고 `index.html`, `style.css`, `app.js`, `data.json`을 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
3. **Settings → Pages**로 이동해 Source를 **Deploy from a branch**로, Branch를 **main / (root)** 로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://내아이디.github.io/insta/` 주소로 접속하면 됩니다.

## 2. 편집하기

- 주소 끝에 `?edit`를 붙여서 접속합니다. 예: `https://내아이디.github.io/insta/?edit`
- 위쪽 검은 툴바의 기능은 다음과 같습니다.
  - **＋ 새 게시물**: 게시물을 올립니다. 아래 탭의 ＋ 버튼도 같은 기능입니다.
  - **👤 프로필·설정**: 아이디, 이름, 프로필 사진, 소개, 팔로워 수, 하이라이트, 로고 글자, 다크 테마를 바꿉니다.
  - **👁 미리보기**: 편집 버튼을 숨기고 방문자에게 보이는 화면으로 봅니다.
  - **⬇ 내보내기**: 지금 상태를 `data.json`으로 내려받습니다.
  - **⬆ 불러오기**: 백업해 둔 `data.json`을 불러옵니다.
  - **↺ 초기화**: 브라우저에 저장된 편집 내용을 지우고 저장소의 `data.json` 상태로 돌아갑니다.
- 게시물마다 있는 **✎ 수정** 버튼으로 다음 항목을 수정합니다.
  - **작성자**: 내 프로필 계정 또는 다른 계정(아이디, 프로필 사진, 인증 배지)
  - **사진**: 여러 장, 순서 변경, 비율(4:5, 1:1, 3:4, 1.91:1)
  - **내용, 위치, 작성 시간**: 시간은 "3 hours ago", "November 17"처럼 적은 그대로 표시됩니다.
  - **반응 수**: 좋아요, 댓글 수, 리포스트, 공유. 숫자만 적으면 `12400`이 `12.4K`처럼 표시됩니다.
  - **댓글**: 추가, 삭제, 순서 변경, 댓글마다 아이디, 프로필 사진, 시간, 좋아요 수, 인증 배지
  - **게시물 순서 변경, 삭제**

## 3. 수정한 내용을 사이트에 반영하기 (중요)

편집 내용은 **편집한 브라우저에만** 자동 저장됩니다. 다른 사람에게도 보이게 하려면 다음 순서로 올려야 합니다.

1. 편집 모드에서 **⬇ 내보내기**를 눌러 `data.json`을 받습니다.
2. GitHub 저장소에서 **Add file → Upload files**로 받은 `data.json`을 올려 기존 파일을 덮어쓰고 **Commit changes**를 누릅니다.
3. 1~2분 뒤 사이트에 반영됩니다.

## 사진 넣는 법

- **파일에서 선택**: 가장 쉬운 방법입니다. 사진이 자동으로 줄어들어 `data.json` 안에 들어갑니다. 사진이 많아지면 `data.json`이 무거워지고 브라우저 저장 공간(약 5MB)이 꽉 찰 수 있습니다.
- **링크로 추가 (추천)**: 사진이 많을 때 씁니다.
  - 저장소에 `images` 폴더를 만들어 사진을 올린 뒤 `images/cafe1.jpg`처럼 적습니다.
  - 또는 이미지 호스팅에 올린 **이미지 주소**를 붙여 넣습니다. 이미지 주소는 이미지를 우클릭한 뒤 "이미지 주소 복사"로 얻을 수 있습니다.

## 참고

- `?edit` 주소를 아는 사람도 편집 모드에 들어갈 수 있지만, 바뀐 내용은 **그 사람의 브라우저에만** 남습니다. 사이트의 내용은 저장소의 `data.json`을 바꿔야만 바뀝니다.
- 방문자가 누르는 좋아요, 저장, 리포스트, 팔로우는 화면에서만 바뀌고 저장되지 않습니다.
- 이 페이지는 비공식 가상 페이지입니다. 실제 서비스와 혼동되지 않도록 하단의 안내 문구를 유지해 주세요.
